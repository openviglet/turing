# Writing a Viglet Turing docs page

**Apply `docs-writing` first.** The shared skill (`~/.claude/skills/docs-writing`) has the
method, the page templates and the style guide; this file has only what is specific to
Turing, and wins where the two differ. Generated by `docs-setup`; a gap here is fixed in
`docs-setup`, then regenerated (hand-written sections marked `<!-- keep -->` survive).

Where a feature is documented, and whether it needs a page at all, is decided first by
`turing-roadmap-docs` (§ Propagating to end-user documentation). Whether a page matches the
code is `turing-docs-sync`. This skill is how the page is written.

## Where the pages are

- Pages: `frontend/apps/docs/src/content/docs/`, `.md`, or `.mdx` when a page uses
  components. Subfolders (`getting-started/`, `integrations/wordpress/`) are part of the slug.
- `frontend/apps/docs/COVERAGE.md` sits *outside* the content folder, so it is not a page.
- Navigation: `frontend/apps/docs/src/sidebar.generated.json` (read by `astro.config.mjs`).
  A new page needs a `{ "slug": "<slug>" }` entry in the group it belongs to, or it builds
  as an unlisted route nobody reaches. Despite the name, the file is edited by hand now;
  never re-run `scripts/port-docusaurus.mjs`, which would overwrite the pages.
- Hubs with card grids: `index.mdx`, `enterprise-search.mdx`, `rag-chat.mdx`,
  `agents.mdx`, `deploy-operate.mdx`. A new page usually earns a `<LinkCard>` on its hub;
  check the hub's text whenever a page's opening promise changes.
- Renamed or removed page: add the old URL to `frontend/apps/docs/redirects.json`; the link
  gate checks every redirect target.

## Framework components (Starlight)

- Steps: `<Steps>` around an ordered list; callouts: `:::note`, `:::tip`, `:::caution`,
  `:::danger`; tabs: `<Tabs><TabItem label>`; cards: `<CardGrid><LinkCard>` (or `<Card>`);
  keys: `<kbd>Ctrl</kbd>`.
- Components need `.mdx` and an import from `@astrojs/starlight/components`. Renaming
  `.md` to `.mdx` keeps the route; the lint reads both.

## Product name and links

- The product is **Viglet Turing** on first mention in a page, **Turing** after; never
  "Turing ES" (dropped 2026-10-17). No naming lint holds this beyond the glossary rule
  below, so the rule is this sentence.
- Public code links point at `openviglet/turing`; the image is `ghcr.io/openviglet/turing`.
- Internal links are root-absolute `/docs/<slug>/#anchor`, never
  `https://turing.viglet.org/docs/...` and never relative. Astro does not prefix hand-typed
  links; `scripts/check-links.mjs` catches one that breaks.

## House style that differs from `docs-writing`

- Internal ids never reach a page: no `T<n>` task ids and no roadmap `Block <X>` labels
  (they belong in `COVERAGE.md`, not on the page). The lint's `internal-ids` rule holds both.
- Brand colours, product naming and the Docker image follow `agents.md` § Visual Identity.

## Coverage

Every user-facing ship records its verdict in `frontend/apps/docs/COVERAGE.md` (✅ documented
/ 🧩 folded into a page / 🔒 deliberately internal, with page and anchor) in the same commit
as the page; the "Orphans" section stays **None**. Keep an anchor that COVERAGE or another
page links to, or update the link in the same change.

## Gates, in order

1. `pnpm --filter turing-docs test`: runs `frontend/apps/docs/scripts/docs-style.test.mjs`,
   the mechanical style rules (root alias `pnpm test:docs`).
2. `pnpm --filter turing-docs build`: `astro build`, then `scripts/check-links.mjs`, which
   fails on any broken internal link, anchor, image or redirect target. Starlight also fails
   on a sidebar slug with no page.
3. `pnpm build:site` before a release: the site build that carries `dist/docs`.

Run them from `frontend/`. Redirect long output to a file and read it, rather than piping a
gate into `grep` and trusting the exit code of `grep`.

## Debt

`BASELINE` in `frontend/apps/docs/scripts/docs-style.test.mjs` lists the pages that still
break a style rule. When you rewrite a page, remove its entries in the same commit; the lint
fails on an entry that is paid. A false positive is fixed in the lists at the top of that
file, never by adding a page to `BASELINE`. The debt is filed in roadkeep Block **AE**
(§CLXXXIV): rewrites of the five largest pages T1279 to T1283, rule-by-rule sweeps T1284 to
T1287, code-to-docs gaps T1288 to T1290.
